In plain English

The killer app of LLMs. Software developers were the first profession to see massive AI productivity gains, and the tools have only gotten better.

Categories: Autocomplete (Copilot, Cursor Tab) — ghost-text suggestions as you type. Conversational coding (Claude Code, Cursor Composer) — chat with your codebase, get diffs. Autonomous agents (Devin, Replit Agent) — give a Jira ticket, get a pull request. App generators (v0, Bolt, Lovable) — prompt → working web app.

Cursor hit $500M+ ARR and ~$10B valuation. GitHub Copilot has 30M+ paid seats. Coding AI is the highest-monetizing AI category bar none.
