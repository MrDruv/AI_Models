In plain English

One API key, 300+ models. Instead of signing up for OpenAI, Anthropic, Google, DeepSeek, Together, etc. separately, you sign up for OpenRouter once. They proxy your requests to the right provider and combine the bills.

Killer features: automatic failover when a provider goes down, price/latency-based routing, free tiers for many open models, and a single dashboard for all your spending. Adds ~5% markup, but pays for itself in flexibility.

Overview

Universal LLM gateway. Write to OpenAI-compatible API once, route to any model with unified billing.

Why use it

Why it's loved

  • Provider preferences (e.g., 'only US providers')

Pricing model

  • BYOK option avoids markup entirely
  • No subscription fee — pay-per-use
