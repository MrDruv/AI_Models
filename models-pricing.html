How to read this page. Input tokens are what you send; output tokens are what the model returns. Output is typically 4–8× more expensive. Reasoning models use hidden "thinking" tokens. Most providers offer Batch API (50% off) and prompt caching (up to 90% off).

Decision Guide · Which model when?

Quick recommendations

Default starting point

GPT-5 or Claude Sonnet 4.6. Both reliable, well-supported, easy to swap.

Maximize savings

DeepSeek V3.1 or Gemini 2.5 Flash-Lite. Combine with Batch API and caching.

Hard reasoning

o3 for premium, DeepSeek R1 for 30× cheaper open alternative.

Coding agents

Claude Opus 4.6 autonomous, Claude Sonnet 4.6 assistive, GPT-5.2-Codex long-horizon.

Long documents

Gemini 2.5/3.1 Pro (2M context) or Claude Sonnet 4.6 (1M).

On-prem & sovereignty

Llama 4, DeepSeek V3, Qwen 3, or Mistral. Open weights = your servers.

Real-time voice

Groq-hosted Llama (500+ tok/sec), Gemini Flash, or Claude Haiku 4.5.

EU compliance

Mistral EU-hosted or self-hosted open models on EU infrastructure.

$
Example cost. Chatbot processing 10,000 user queries/day, avg 500 in + 300 out tokens. Daily: 5M input + 3M output tokens.
GPT-5 ($1.25 / $10): 5 × $1.25 + 3 × $10 = $36.25/day ≈ $1,090/month
DeepSeek V3.1 ($0.15 / $0.75): 5 × $0.15 + 3 × $0.75 = $3/day ≈ $90/month
