# AI Models Ecosystem Catalog

A comprehensive collection of insights, pricing, and detailed documentation for the global AI ecosystem. This repository serves as a centralized resource for understanding various AI models, platforms, and their respective capabilities.

## 🚀 Overview

This repository contains a structured set of HTML resources that provide in-depth information on:
- **Major AI Providers:** Anthropic, OpenAI, Google, Meta, Mistral, and more.
- **Specialized Domains:** Healthcare AI, Legal AI, Finance AI, Robotics, and Creative AI.
- **Infrastructural Components:** TPUs, GPUs (NVIDIA, AMD, Groq), and Cloud Providers (Azure, Vertex AI, Bedrock).
- **Frameworks & Tools:** LangChain, LlamaIndex, PydanticAI, AutoGen, and MCP.
- **Model Categories:** Multimodal, Reasoning, Code Generation, Image/Video Generation, and Audio.

## 📁 Repository Structure

- `index.html`: The main dashboard for the AI Ecosystem.
- `models-pricing.html`: Comparative analysis and pricing details for various AI models.
- `details/`: A directory containing 70+ detailed reports on specific AI technologies and organizations.
  - Examples include: `openai.html`, `deepseek.html`, `rag.html`, `mcp.html`, etc.

## 🛠️ Usage

Simply open `index.html` in any modern web browser to navigate the ecosystem map. Use the `models-pricing.html` page to compare cost-efficiency across different LLM providers.

## 🌐 Key Topics Covered

- **Core Models:** GPT-4, Claude 3, Gemini, Llama 3, Qwen, DeepSeek.
- **Security & Policy:** EU AI Act, US Policy, Alignment, and AISI.
- **Developer Ecosystem:** SDKs, APIs (OpenAI, Anthropic), and Model Serving (vLLM, Fireworks).
- **Emerging Tech:** Computer Use, MCP (Model Context Protocol), and Reasoning models.
